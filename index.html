나의 이메일 서명 만들기

내 정보를 입력하고 복사하면 끝. 회사 로고와 주소는 같은 형식으로 유지됩니다.

1. 내 정보 입력

필수 항목

입력한 정보는 이 페이지에서만 처리하며 서버에 전송하거나 저장하지 않습니다. 선택 항목을 비우면 해당 항목은 서명에서 빠집니다.

2. 서명 미리보기

입력 전 예시

원래 서명 크기로 표시됩니다. 좌우로 움직여 확인하세요.

정보를 입력한 뒤 서명을 복사하세요.

서명을 선택했습니다. Ctrl+C (Mac: ⌘C)로 복사한 다음 Gmail에 붙여 넣으세요. 모바일에서는 선택 영역의 복사 메뉴를 이용하세요.

로고 이미지 주소 확인 / 변경

GitHub Pages에서는 같은 폴더의 assets/arica-logo.png를 자동 사용합니다. 로컬 파일을 열었다면 배포된 PNG의 전체 HTTPS 주소를 입력하세요. 로그인 없이 열리는 주소여야 합니다.

주소를 바꾸면 입력한 서버에서 로고 이미지를 불러옵니다.

3. Gmail에 붙여 넣기

  1. 컴퓨터에서 Gmail → 설정 → 모든 설정 보기 → 일반 → 서명을 엽니다.
  2. 새로 만들기로 서명을 만든 뒤, 편집 칸에 Ctrl+V (Mac: ⌘V)로 붙여 넣습니다. 서식 없는 붙여넣기는 사용하지 마세요.
  3. 새 이메일과 답장에 사용할 기본 서명을 선택하고 맨 아래 변경사항 저장을 누릅니다.
  4. 테스트 메일을 보내 로고와 링크를 확인합니다. Gmail 모바일 앱의 텍스트 서명과는 설정이 다릅니다.

로고와 회사 주소는 공용 정보입니다. 개인 연락처를 소스 코드에 넣어 배포하지 마세요. 메일 수신자의 설정에 따라 외부 이미지가 숨겨질 수 있습니다.
