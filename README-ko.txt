아리카 Gmail 서명 생성기

사용
1. https://peterkim0930.github.io/arica-signature/ 에서 이름과 연락처를 입력합니다.
   이메일은 아이디와 도메인을 나눠 입력합니다. 기본 도메인은 aricacorp.net이며 변경할 수 있습니다.
   전체 이메일을 아이디 칸에 붙여 넣으면 자동으로 분리합니다.
2. 서명 복사를 누른 뒤 Gmail 설정 열기를 누릅니다.
3. 일반 설정에서 아래로 내려 서명 → 새로 만들기를 선택하고 Ctrl+V(Mac: ⌘V)로 붙여 넣습니다.
4. 기본 서명을 지정한 뒤 맨 아래 변경사항 저장을 누릅니다.

컴퓨터 Gmail에서 설정하세요. 여러 계정 사용 시 적용할 계정을 확인하세요.
Gmail 링크는 일반 설정을 열며 서명 항목으로 자동 스크롤하지 않습니다.

전화번호
- 휴대전화, 서울·지역번호, 070·080, 050, 15xx·16xx·18xx 대표번호를 자동으로 구분합니다.
- 기존 하이픈과 공백을 정리합니다. 국제번호·내선·알 수 없는 형식이나 초과 길이는 자르지 않고 그대로 둡니다.

배포
index.html, assets/arica-logo.png, .nojekyll을 main 브랜치 루트에 유지합니다.
GitHub Pages는 main / (root)를 배포합니다. 별도 빌드나 라이브러리가 필요 없습니다.
로고 PNG 원본, 회사명, 주소와 서명 배치는 유지했습니다.
입력한 직원 정보는 저장하거나 서버에 전송하지 않습니다.
