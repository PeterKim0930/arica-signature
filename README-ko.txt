아리카 Gmail 서명 생성기
=======================

사용 방법
1. GitHub Pages에 이 묶음의 index.html, assets 폴더, .nojekyll 파일을 올립니다.
2. 배포된 페이지 주소를 엽니다.
3. 이름, 부서·직책, 전화번호, 이메일을 입력합니다. 이름만 필수입니다.
4. 서명 복사를 누르고 Gmail의 설정 → 모든 설정 보기 → 일반 → 서명에 붙여 넣습니다.
5. 기본 서명을 지정하고 변경사항을 저장합니다. 테스트 메일로 로고와 링크를 확인하세요.

GitHub Pages 배포
- ZIP을 풀고 index.html이 저장소 최상단에 오도록 업로드합니다. ZIP 자체를 올리는 것이 아닙니다.
- 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
- 배포할 브랜치와 / (root)를 선택하고 Save를 누릅니다.
- Pages 화면에서 표시되는 실제 HTTPS 주소로 접속합니다. 배포 반영까지 시간이 걸릴 수 있습니다.
- assets/arica-logo.png가 로그인하지 않은 브라우저에서도 열리는지 확인합니다.
- 계정/저장소 설정에 따라 Pages 이용 조건과 공개 범위가 다릅니다. 공개 배포라면 회사 로고와 주소가 인터넷에 공개됩니다.

파일 구성
index.html               생성기. 외부 라이브러리나 빌드 과정이 필요 없습니다.
assets/arica-logo.png     사용자가 제공한 247×192 PNG 원본. 재압축/확대하지 않았습니다.
.nojekyll                정적 파일 배포용 빈 파일.
README-ko.txt            이 안내.

로고와 디자인
- 기존 로고 왼쪽, 텍스트 오른쪽 배치를 유지했습니다.
- 로고 표시 폭 148px, 높이 약 115px, 본문 13px/줄간격 1.8, 회사명 15px입니다.
- 원본의 화소 수를 늘리는 업스케일링은 하지 않았습니다. 더 높은 선명도가 필요하면 공식 고해상도 PNG로 assets/arica-logo.png를 교체하세요.
- 회사명과 주소는 기존 HTML의 문구를 그대로 유지했습니다. 주소의 도로번호 등은 추측하여 추가하지 않았습니다.
- 로컬 파일을 바로 열어도 내장 로고로 미리보기를 볼 수 있습니다. Gmail 복사에는 공개 HTTPS 이미지 주소가 필요합니다.
- GitHub Pages에서는 현재 페이지를 기준으로 assets/arica-logo.png의 절대 HTTPS 주소를 자동 생성합니다. 사용자/프로젝트 Pages, 하위 경로를 지원합니다.
- 다른 이미지 호스팅을 쓰려면 '로고 이미지 주소 확인 / 변경'에서 공개 HTTPS PNG 주소를 입력하세요. 입력한 서버에서 로고를 불러옵니다.
- GitHub 파일 보기 페이지 URL, 로컬 경로, data: URL은 Gmail용 로고 주소로 쓰지 마세요.
- 이미지 주소나 파일을 없애면 이미 발송된 메일에서도 로고가 보이지 않을 수 있습니다. 안정적인 주소를 유지하세요.

개인정보
- 배포 파일에는 특정 직원의 실제 이름/전화/이메일을 넣지 않았습니다.
- 입력 내용은 브라우저 내에서만 처리합니다. 서버 전송, 쿠키, 분석 도구, 로컬 저장 기능이 없습니다.
- 페이지를 새로 열면 직원 정보는 다시 입력해야 합니다. 브라우저 자체 자동 완성은 별개입니다.
- 개인 연락처가 들어 있는 과거 HTML은 배포 ZIP에서 제외했습니다. 기존 파일은 별도 보존했습니다.

복사 문제 해결
- 일반 붙여넣기 Ctrl+V 또는 Mac의 ⌘V를 사용합니다. '서식 없이 붙여넣기'는 표와 로고를 없앱니다.
- 자동 복사가 안 되거나 텍스트만 붙으면 '직접 선택하여 복사'를 누른 뒤 Ctrl+C/⌘C로 복사하세요.
- 로고가 안 보이면 이미지 주소, 파일 이름 대소문자, assets 폴더 위치, 로그인 없는 이미지 접근을 확인하세요.
- Gmail 모바일 앱의 텍스트 서명과 웹 Gmail의 HTML 서명은 다릅니다. 설정은 컴퓨터 웹 Gmail에서 권장합니다.
- 메일 수신자의 외부 이미지 차단 설정, Gmail/메일 클라이언트의 처리 방식 때문에 표시가 달라질 수 있습니다.

검증 범위
- 자동 검사 13개 통과: 주소 생성, HTML 이스케이프, 선택 항목 생략, 입력 검증, 로컬/실패 이미지 복사 차단, HTML/일반 텍스트 클립보드 형식, 복사 실패 대체 동작, 중복 클릭 방지, 초기화, 원본 로고 보존.
- Chromium에서 입력/미리보기와 서명 복사 버튼을 확인했습니다. 로컬 테스트용 이미지 주소를 쓰는 별도 테스트 페이지에서 실제 붙여넣기 후 표·로고·이메일 링크가 유지됨을 확인했습니다. 테스트 전용 페이지는 ZIP에 포함하지 않았습니다.
- 320px, 390px 너비에서 페이지 가로 넘침이 없는 것을 확인했습니다. 서명 미리보기만 원래 폭을 유지하고 좌우 스크롤합니다.
- 배포 후 실제 GitHub Pages 공개 URL과 로고 URL의 접근을 확인하세요. Gmail 계정의 서명 저장과 실제 메일 발송/수신은 테스트 메일 1통으로 최종 확인하세요.
